# 沐沐健康

面向个人使用的安卓饮食与训练日记。界面参考 iOS「提醒事项」的分组列表，可选择五套主题配色；记录保存在手机内部，无需账号。

## 安装与使用

安装包：`build/mumu-health-v1.0.5.apk`。发送到安卓手机后打开，按手机提示允许该来源安装。支持 Android 8.0 及以上；请保持 Android System WebView 更新。新版沿用原签名，可覆盖安装并保留已有记录与 AI 设置。

1. 打开「我的 → AI 配置」，填写服务地址、API Key、文字模型与图片模型，点击「保存设置」。
2. 可点击「测试文字连接」检查文字模型。图片模型是否可用，需要通过实际图片识别确认。
3. 在「今天」选择早餐、午餐或晚餐，输入食物描述，或拍照、从相册选择图片。
4. 直接点击「保存这一餐」；记录立即出现，AI 在后台估算，完成后自动更新总热量。列表先显示餐食名称与约多少千卡，点开可看食物明细与估算说明。
5. 若分析失败，记录仍在，可点开重试或手动补充。手动添加食物与热量无需联网；热量可留空，汇总只计算已知项。
6. 「训练记录」可填写有氧的名称与分钟数，或力量训练的动作、组数、每组次数和可选重量。点击「添加运动」一次填写多项，也可以混合有氧与力量；全部校验通过后一次保存，列表仍逐项显示、编辑与删除。
7. 在「历史」切换日期，查看或补充过去的记录。日期栏固定显示周一至周日，同周选择日期不会移动日期栏。左右箭头切换上一周、下一周，并保留所选星期。点已有记录可修改和删除。

## 我的与外观

「我的」首页仅显示设置、外观、AI 配置、训练模板和检查更新五个入口。数据备份放在设置里，服务地址、密钥及模型放在 AI 配置里；点击入口后再编辑。安卓返回键先回到「我的」菜单。

「我的 → 外观」可选择晴空蓝、鼠尾草绿、雾紫、玫瑰粉或暖杏。点选立即生效，统一调整首页、历史、编辑表单的底色与强调色，安卓状态栏与导航栏同步背景。配色保存到手机，下次打开保持；切换外观不会改动 AI 密钥与已有记录。

## 力量训练模板

「我的 → 训练模板」可以新建、编辑或删除模板。初次提供练腿、练背、练胸、练肩四个可编辑模板；重量留空，请设置自己的常用重量。每个动作可以设置名称、组数、每组次数、重量和备注。

记录训练时，点击模板名称直接带入默认动作。已有内容会保留，新动作追加在后面。带入后可以针对这次训练修改；修改本次记录不会改变模板，修改或删除模板也不会改动已保存的训练。

模板保存在手机里并纳入导出备份。恢复不含模板的旧版备份时，会保留手机当前的模板。

多条记录可以归入同一餐；当天餐次按早餐、午餐、晚餐去重计数。训练不计算热量消耗或热量差。

## AI 接口

支持使用 Bearer API Key 的 HTTPS Chat Completions 格式接口，可以分别配置文字和视觉模型。

预填的是百炼北京地域兼容接口和 `qwen-plus` / `qwen3-vl-plus`。使用其他服务时，请同时修改服务地址、密钥与模型名称。百炼新业务空间可以填写专属域名地址，具体以你控制台为准。

- [百炼兼容接口文档](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)
- [百炼视觉模型接口文档](https://help.aliyun.com/zh/model-studio/qwen-vl-compatible-with-openai)

图片会先旋转校正、缩小并重新编码为 JPEG，然后以 Base64 发给视觉模型。描述会一同发送。APP 不会将历史饮食或训练发送给模型。

密钥由 Android Keystore 的 AES-GCM 加密保存，已保存的密钥不会返回界面。导出的备份不包含密钥。请求使用你自己的服务额度；遇到密钥、权限、额度或网络问题，会显示错误，可继续手动记录。

AI 热量属于估算。食物份量、做法和用油会影响结果；点开记录可查看明细并修改，无法估算的项显示为未知。APP 被关闭时，未完成的分析会保留为待处理状态，重新打开后继续尝试。

## 数据备份

「我的 → 设置 → 导出记录与照片」可以保存 JSON 备份，包含饮食、训练、力量模板和已记录的照片。

「从备份恢复」选择原备份文件后，APP 会展示记录数量并要求确认。恢复将替换当前记录，先导出当前数据。恢复时会为照片生成新文件名，失败不会覆盖原记录或原照片。

卸载 APP 会清除手机上的记录。个人使用没有云端同步，换手机前请导出备份。保存需要 AI 估算的文字或照片后，本次内容会发送给所配置的服务；手动填写食物热量时不发送。

## 从 GitHub 更新

安装本版后，APP 每次打开会检查仓库的最新 GitHub Release。发现更高版本会提示「立即更新 / 稍后再说」；取消后仍可在「我的 → 检查更新」检查并安装。已安装 1.0.4 更新功能的用户可直接检查并覆盖更新；更早版本需先手动安装 GitHub 最新 Release。下载后 APP 会校验文件大小、SHA-256、应用包名、版本号及与当前 APP 相同的签名，再调用安卓系统安装界面。首次更新可能需要授权此 APP 安装未知来源应用；授权后返回「我的」再点「立即更新」。更新过程中手机需要能访问公开的 GitHub Release。

`.github/workflows/release.yml` 在 `main` 每次推送后构建一个签名 APK，发布为唯一的最新 Release；**新版本成功发布后**删除旧 Release 和对应标签，因此 GitHub 只保留当前安装包。失败时保留此前可用的版本。版本名称取自 package.json 并追加构建序号，版本编号按构建序号递增。此工作流需要在仓库 `Settings → Secrets and variables → Actions` 配置两个 Repository secrets：

- `MUMU_SIGNING_KEY_BASE64`：当前 `.tools/signing/mumu-personal.jks` 文件的 Base64 内容。
- `MUMU_SIGN_PASSWORD`：当前 `.tools/signing/credentials.json` 中的 `password`。

这两个值必须来自已安装版本使用的原签名，不能重新生成，否则安卓无法覆盖安装且本地数据会受到影响。Windows PowerShell 可分别运行以下命令，将值复制到剪贴板后立即粘贴到相应 Secret；不要提交或分享输出：

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes((Resolve-Path '.tools/signing/mumu-personal.jks'))) | Set-Clipboard
(Get-Content '.tools/signing/credentials.json' -Raw | ConvertFrom-Json).password | Set-Clipboard
```

仓库必须公开，手机才能无需 GitHub 登录读取版本和下载 APK。仓库 Actions 工作流需要 `contents: write` 权限；工作流已声明该权限。只有修改 `main` 并推送才触发自动发布，单纯上传 APK 或改动其他分支不会触发。发布状态可在 GitHub 的 Actions 页面查看。

## 开发

原生 Android Java 负责私有数据文件、Android Keystore、HTTPS AI 请求、相机与图片选择及系统文件导入导出。应用内的离线 WebView 负责界面。安装包不加载远程界面代码，也不包含任何真实 API Key。

### Windows 构建

需要 Node.js 和 JDK 17：

```powershell
npm.cmd ci
& .\tools\setup-android.ps1
& .\tools\build-android.ps1 -JdkPath '你的 JDK 17 目录'
```

脚本从 Google 官方仓库下载 Android 35 平台和构建工具，校验 SHA-1。构建流程包含界面打包、资源编译、Java 编译、DEX 转换、对齐及签名验证。

签名文件保存在 `.tools/signing/`，请自行妥善备份。后续更新必须沿用该签名，才能覆盖安装并保留手机中的记录。该目录已加入 `.gitignore`。

也提供了 Android Studio / Gradle 项目配置（AGP 8.9.2，Gradle 8.11.1，JDK 17）。界面源代码修改后需先运行 `npm.cmd run build:web`。本项目直接构建脚本无需安装 Android Studio。

### 预览和检查

```powershell
npm.cmd run build:web
npm.cmd run preview
npm.cmd test
npm.cmd run test:ui
```

浏览器预览地址为 `http://127.0.0.1:4173`，只提供界面与本地预览数据。浏览器预览不会执行真实 AI 请求或保存密钥。真实拍照、加密存储和 AI 调用在安卓安装包内运行。

界面测试使用明确标识的 AI 测试夹具覆盖先保存、后台回填、详情查看和手动修正，没有调用真实服务。安卓原生测试位于 `tests/android/TestInstrumentation.java`，仅加入 debug 包：

```powershell
& .\tools\build-android.ps1 -Debug
adb install -r .\build\mumu-health-debug.apk
adb shell am instrument -w com.mumu.health/com.mumu.health.TestInstrumentation
```

原生测试使用隔离的测试目录与偏好配置，覆盖记录持久化、校验、恢复、删除、密钥加密、返回解析和图片压缩。
